# cusco-data

Compilation of datasets for the Cusco Region and its districts, and the data behind **Cusco-stats**, an interactive explorer of the 116 districts of Cusco, Peru, published at [pvillaparo.github.io/cusco-data](https://pvillaparo.github.io/cusco-data/).

| Folder | Content |
|---|---|
| `SIRTOD/` | Raw INEI SIRTOD data for Cusco (download of 22 September 2026); see `SIRTOD/info.md` |
| `panels/` | District-year panels: canon and municipal finance, development indicators, census baselines |
| `harmonized/` | Display-ready dataset for the plots (district, province and department), with bilingual labels |
| `website/` | Export scripts, place names, boundaries and the design plan for the explorer |
| `docs/` | The explorer app and its data, served by GitHub Pages |

Each folder has its own README explaining sources, choices and caveats.
